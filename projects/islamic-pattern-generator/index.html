Procedural design · 2024

Islamic pattern generator

A Houdini tool that lets artists build Islamic geometric patterns from the traditional construction rules, without touching the node network underneath.

My role
Research, tool design and build. I taught myself Houdini for this project and designed the interface around how artists already work.
Tools
SideFX Houdini (HDA), procedural and node-based design.
Outcome
More than 15 tileable patterns from a single rule-based system — the same thinking behind a brand pattern or template library.
